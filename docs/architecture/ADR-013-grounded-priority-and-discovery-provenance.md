# ADR-013: Ground contextual advice and qualify discovery provenance

Accepted for local implementation, 2026-10-07. Corrects the independent review of 286bf7c without replacing native research, lowering budgets, removing candidates or changing intrinsic strength/admission.

`contextual-priority-v2` requires resolved identity, an active verified supported defining observation and active verified supported priority-cited evidence. Provider-final-identity uncertainty cannot substantiate that evidence. Without this grounding, priority is null and proposed use/wrap/adapt is held at study; watch/reject remain conservative. `proposedAction` preserves the original model proposal in the query item. All candidates remain inspectable and manually saveable. The frozen schema-v1 recommendation extension excludes ungrounded items. Its existing contextual extension accepts v1 and v2 policies; its schema version remains 1. Old retained snapshots and intrinsic policies remain unchanged; deriving a current view does not rewrite the old bytes.

Discovery is reconciled against request capture identities and configured followed parents. Candidate-named recorded queries are model nominations, not demonstrated unknown-name discovery. Parent outlink matching stays separate from configuration and mechanism assertions. A model-reported unseeded query is explicitly labelled model-report; it is not a verified search trace. The original proposed mechanism is retained when corrected. These rules do not infer semantic relevance from words or invent introducing searches.

Successful kernel retrieval conflicting with an explicit earlier model access failure produces a stale-assessment diagnostic. Original gaps, unknown dates, unmatched claims and scores are preserved. Available extracted publication metadata is labelled as such, not promoted to a maintenance judgment. No second model pass is added by default.

Followed-source acquisition runs outside the writer lock. A short read/merge/write protects state after transport; an empty scan needs no lock. Corrupt/busy supplemental state becomes a visible research gap, while cancellation still aborts. Private background scans count scans/opportunities, not result exposures. Verified configured-parent links reaching a research result and links returned by an explicit source scan count result exposures. Historical exposure totals remain historical; the new `resultExposures` counter identifies post-correction result-link counts without fabricating past engagement.

Explicit useful/skip/mute feedback replaces each entity's prior vote at its verified configured parent. Notes and votes stay private. Saved-entity feedback can recover its retained selection trail; old unverified trails earn no source credit. A source-state failure cannot discard a saved personal note and is reported separately. Numeric source feedback is a sum of explicit votes, not evidence strength or a model-invented benefit.

Hosted Jina fallback is allowlisted to timeout and parse failures. HTTP denial/rate-limit/server errors, cancellations and transport safety failures never dispatch it. Denial matching reads protocol status/warning headers, not article discussion of response codes. Final identity uncertainty and automatic-admission guards remain.

Equal contextual scores retain stable entity-identity ordering; intrinsic strength remains separate. Source-family coverage is model-reported, not verified by aggregate search counts. SearXNG remains explicitly public-HTTPS-only: loopback/self-hosted HTTP endpoints are unsupported rather than silently granting a private-network transport exception. Native research and source-only acquisition remain working alternatives; no service is installed or selected as default.

The reviewed three paired runs used one model call each. Native was 1.7–1.9 times faster; Signals added one obscure useful lead and a newer status fact, but missed useful authoritative/recurrence coverage. The traces do not isolate schema-generation versus kernel-fetch latency. These repairs correct downstream honesty and durability; they do not establish better research or latency. A fresh independent discriminating case remains necessary under normal live-slot allocation. No new orchestration, default repeated assessment, paid provider or recurrence is introduced.
