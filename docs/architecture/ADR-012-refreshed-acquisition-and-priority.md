# ADR-012: Task-directed acquisition and separate contextual priority

Accepted for local implementation, 2026-10-07. Supersedes ADR-011's default three-endpoint acquisition and shallow combined tool allowance; historical strength/replay and schema-v1 meanings remain unchanged.

Native host research owns interpretation and query directions. Automatic headless research uses permitted native web tools, with search and read budgets accounted separately. Model-free public APIs remain usable explicitly (`--sources-only`), or as a selected supplemental provider. They are no longer an implicit software/encyclopedia bias on every question. The one kernel retains every provisional candidate and source failure; discovery quality is measured separately from corpus admission.

Static document extraction adopts Readability 0.6.0, inert Linkedom 0.18.13 and rss-parser 3.13.0 behind existing safe transport. Original links survive article cleanup. Jina is a configured public-only fallback; access denial never triggers it and final identity/truncation uncertainty remains explicit. Docling is an optional isolated Python bridge with selected local model artifacts and page/table locators. No HTML/text page requires Python. Scripts/resources are never executed. Public transport still pins DNS and bounds redirects, bytes and time.

last30days 3.26.0 (`7f582ad8c2e140eca08098b245f9e31b68e28b60`, MIT) supplies source-only versioned JSON 1.3 / discovery 1.1. Its wrapper selects the inspected HN lane, isolates HOME/config/PATH, explicitly disables Keychain and browser cookies, and never imports presentation, hooks, updates, watchlists or credentials. Actual HN trials reported unreachable, so it is optional rather than default. SearXNG is a configured JSON endpoint, with explicit denial/schema drift. GPT Researcher 0.16.0 (`0957c301ed06c2a5857b834358c7227c739041d4`) is a fixed bridge returning original source material; only explicitly selected API environment references and an authorized budget permit invocation. Pro supplies no assumed SDK credit. No provider writes the Corpus or chooses scores.

Followed sources supplement broad exploration. Actual exposure, new-link opportunity counts, origins and absent feedback are retained privately. Byte/content changes remain unassessed until semantic review; a fetch timestamp is never a novelty signal. The same writer/scheduler owns durability. Second Brain OS informs raw-versus-derived separation; derived judgments cannot become independent sources. Kotaemon informs passage-first evidence navigation. TrendRadar informs source/delta behavior without another scheduler. GraphRAG, LightRAG and PageIndex remain challengers for an observed retrieval gap.

Hyperresearch is a standalone comparison in disposable planning state. Its hooks/16-step pipeline are not nested in Signals; source vault reuse can be evaluated without enabling global hooks or trust bypass. PaperQA2 is a funded specialist trial only. PaperMage's maintenance finding excludes it as default. Primary-source inspections and actual trials are retained privately in the planning reset artifacts, with failures and costs unknown unless measured. Reopen a default only on same-task useful-result evidence, rather than help/import success or upstream benchmark claims.
