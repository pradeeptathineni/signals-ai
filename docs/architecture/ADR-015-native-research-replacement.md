# ADR-015: one native research task and retained opportunities

Status: accepted for local implementation, 2026-10-08. Supersedes ADR-014's full-assessment routing and implicit Deep reassessment; historical records and score/interchange policies retain their meanings.

Search Signals uses the invoking AI, or one explicitly configured headless native session, to produce a readable original answer and a compact native brief v3. The answer arrives before source verification. Candidate/observation validation isolates malformed items; valid siblings survive and invalid leads remain visible but unsavable. Syntax failure preserves recoverable answer text without inventing facts. Legacy native brief v1/v2 and full proposals remain ingestion decoders; they are not competing research engines. The assessed route is a compatibility alias to the same native task.

The previous equivalent full-discovery prompt/schema branch and default second extraction stage are removed. Explicit `--review` is a specialist no-web reassessment of fetched evidence; it never runs on ordinary/deeper research by default. Failed optional review preserves original observations and a visible gap. No new runtime dependency or agent manager is added.

Native search/read owns uncertain exploration. Existing bounded GitHub topic/star/recent pages, RSS and static readers supply unassessed locators. Native-authored acquisition plans can share compatible locator pools; each different need keeps independent reasoning, context and status. Exact duplicate requests may replay within an activation. Scope disagreements fail explicitly and interests can opt out.

Evidence/scoring remains source-bound and versioned. Unknown dimensions earn zero, so an interesting learning resource may have a low index. Manual retention preserves it without automatic admission or publication. Context consumes advisory evidence and owns project selection/execution. Source inspection and first-party trials do not establish independent corroboration or human usefulness.

Finite due and query-list activations share a process-owned lease, support cancellation and retain interrupted work. Maintenance checks HTTP validators or content hashes before inference: unchanged primary material completes without renewing claims; access denial keeps the previous record and visible gap. Changed material requires interpretation before a claim/decision delta. Unchanged primary material says nothing about new independent sources; explicit research remains available for that need.

The existing portal exposes Search Signals, Inbox, Corpus, Interests, Sources, Jobs and Settings. Saved-Corpus follow-ups bind identities to the selected public/private store. Public site/export remains derived from explicitly selected public facts. Privacy, safe transport, origin/token checks, immutable history, score replay and restore remain required boundaries.

Historical comparisons justified removing overhead but do not measure the replacement. Current comparisons and migration receipts live in the dated sister planning folder. No broad research superiority, savings, user novelty or usefulness is asserted. Production recurrence/publication remains opt-in and stopped for local delivery.
