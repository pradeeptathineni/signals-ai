# ADR-005: Signals v1 evidence exchange and scoped readiness

Status: accepted. Date: 2026-10-05. Preserves ADR-004 and historical scoring/replay.

Signals AI is the settled public name approved by the user on 2026-10-05. The active local
directory and retained PostgreSQL resources keep their names during this session.

The existing bounded research protocol owns model planning/synthesis. Existing authoring,
PostgreSQL transactions, immutable revisions and Corpus retrieval own durable knowledge.
The frozen kit evidence-bundle schema v1 owns peer interchange; Ajv 2020 plus ajv-formats
validate it without modifying inputs. Domain checks enforce digest integrity, IDs, references,
safe public URLs, budgets, categorical signals and fixture/privacy boundaries. Checks establish
mechanical conformance; the explicit reviewer assesses whether sources support claims.

Drafts remain operational and untrusted. Explicit human or `agent-reviewed` admission records
actor/policy/rationale and creates public evidence plus Corpus document bindings atomically.
An agent review is never described as human review. Imported mode cannot claim a configured
model ran; only a stored completed research projection may use model-led mode. Historical
decision-input bundles keep their original format, names and hashes.

Bundle recommendations are advice. Adoption readiness is a separate categorical policy;
supported interfaces and successful bounded checks permit trials without popularity thresholds
or exhaustive comparisons. Unsafe authority, incompatible functionality and missing critical
support block the requested action. Reference, copying and production use need different evidence.

Refresh adds a successor, retains exact old bytes and distinguishes material changes from a
timestamp-only recheck. Consumer feedback binds an exact bundle/candidate/task and remains local
observed evidence; it cannot corroborate itself or automatically activate a capability. The
exchange is a projection, not a second runtime or a replacement for the research database.

Options considered: extending the legacy decision-input bundle would break its distinct privacy
and replay contract; exporting all database internals would leak operational/private state;
building a loadout composer would duplicate Context's ownership. Revisit the narrow exchange
only for a demonstrated consumer gap and version breaking changes rather than rewriting v1.
