# ADR-011: Live entity discovery with the user's AI

Accepted 2026-10-05. Supersedes ADR-009's new-save gate and offline-only boundaries for native entities. Historical findings retain `signal-review-v1`; frozen interchange and retained data stay unchanged.

Signals owns one live request → acquisition → fetched evidence → identity → deterministic assessment operation. Existing coding agents use the `signal-search` Agent Skill and their native tools, then call the common helper. Headless clients supervise installed Codex `exec`. Codex retains authentication; Signals passes only queries and public evidence. Ignored private settings select model/effort references, never credentials.

Primary interface references inspected: [Agent Skills](https://agentskills.io/specification), [Codex noninteractive](https://developers.openai.com/codex/noninteractive), [Codex configuration](https://developers.openai.com/codex/config-reference), [PROV](https://www.w3.org/TR/prov-overview/), [SKOS](https://www.w3.org/TR/skos-reference/). These justify interfaces and lineage, not the project weights or comparative superiority. Node primitives avoid another dependency/service. A future Claude host maps its existing search/fetch and stdin helper to the same contract; a text model alone is not live acquisition.

Responsibility map: keep legacy file Corpus, frozen interchange, filters, retained snapshots and browser tools; adapt UI/build/writes for native entities; replace active research instructions that defer acquisition; new gap filled by bounded live kernel, installed runner, local bridge, merge and due-once scheduling. No database, general agent runtime, candidate execution or stable release.

The frozen standard trial exposed a mismatch between social adoption and normative authority. Adopt a fixed standard profile (C10/M15/F25/H40/V10, adoption not applicable) rather than renormalizing missing fields or forcing popular software rankings onto standards. ISO catalogue evidence earned75 under this declared profile versus38 under the original profile; full normative text and conformance outcomes remain unverified. Expiring mutable formal-status checks require separate actual-check receipts; immutable publication/first-fetch evidence does not become new merely because an AI reads cached text.

The all-concept gate snapshots140 current Context concepts as research inputs, separate from the unchanged development pin. Retain one sequential reasoning worker and bounded resumable query lists instead of a parallel agent runtime. A value-model pilot completed quick acquisition/extraction but exposed thin choices and invalid indicator bindings; use a discriminated extraction schema and trial balanced discovery with value-model extraction. Routing is explicit configuration, not a claim of measured token/cost savings. Reopen it if representative evidence quality or completion rates degrade.
