# ADR-017: query assessment and accumulating Library

Status: accepted for local implementation, October 10, 2026. Successor to ADR-016's literal default and ADR-011's active scoring policy. Historical records and policies retain their original meaning.

One native research task returns the interpreted need, required constraints, resource types and time window. `query-relevance-v1` uses 0 conflict, 25 topic-only, 50 partial/material limits, 75 direct/secondary limit, 100 direct/all inspected required constraints, null unsupported. Reasons bind to inspected sources; relevance then stable identity determines order. Correcting interpretation starts a distinct assessment and retains the prior run. Retrieval rank, query fit, intrinsic Signal and project usefulness remain separate.

Native brief v4 selects `signal-strength-v7`. Four source-bound rubric dimensions—claim/identity basis, inspectable work, external scrutiny, applicability/limits—use ordinal levels 0–4, ordinarily 25 points each. Standards use 40/20/10/30. Contribution equals weight × supported level ÷ 4; sum unrounded contributions and round once to the nearest integer, halves upward. Type rubrics explain suitable evidence. These are initial policy judgments, not probability or universal cross-type comparability.

Successor correction: active brief v5 selects `signal-strength-v8`. A generic source-grounded regression demonstrated that v7 discarded inspected prerequisites/licence scope bound to applicability as verification/inspectable. v8 permits that evidence class for ordinary applicability at level 1 only; standards and every other gate, ceiling and weight remain unchanged. The model still establishes semantic relevance to scope. User-specific task/model/provider/project suitability belongs to query relevance, not an intrinsic decisive gap unless evidence concerns the item's own advertised scope or status. v4/v7 and implicit historical judgment proposals replay unchanged. New explicit v8 proposals and brief v5 use the successor. The frozen live study remains evidence for the pre-fix source and policy.

Unknown dimensions earn no credit and remain unknown. Unresolved decisive work/status/identity/contrary evidence yields null, a reason and next inspection. Explicit nondecisive uncertainty permits provisional scores. Independent origin/publisher evidence governs scrutiny; software attention contributes at most five points using existing logarithmic anchors and the strongest measured counter. Promotion, copied reports and adverse findings cannot manufacture independent scrutiny; material failures constrain work/applicability. Every substantive candidate retains a disposition.

Model-proposed levels are ceilings, not automatic credit. General evidence classes cap inspectable material at level 1, worked examples at 2, independent applied evidence at 3, and replicated evidence at 4. Identity/status criteria separately distinguish secondary accounts, primary authority, recognized authority, and formal current status. Standards require issuer authority and current normative status. Future or stale material earns no current credit; unsupported caps and uncertainty remain inspectable in the assessment reasons.

The normal decoder supports up to 24 facts per candidate and 240 overall. Defining/adverse observations receive retention priority. Invalid/overflow/deferred facts are counted and prevent automatic admission. Search/document/time/cancellation limits remain. Native v1–v3 and strength v0–v6 retain their historical readers and meanings.

Library uses qualified format/destination identities over public native, private native and eligible historical records. Private leads retain immutable saved contexts without manufactured evidence. Research consumes a bounded evidence-only projection, keeps historical claim labels and reports failed stores/omissions. Historical `corpus-query` retains its explicitly legacy output; `library-query` uses the current collection.

Submitted Library queries keep immediate indexed results. After explicit metadata-egress permission, one authenticated no-web operation can select any retained record in the bounded population, including nonliteral matches. Query, qualified key, title, bounded description, kind, capabilities and tags may leave the machine; notes, projects, source text and credentials are excluded. Code validates IDs/scope/filters and hydrates original records. Initial bounds: 200 records, 48,000 serialized characters, 120 seconds; omissions and unavailable/cancelled states are visible. No invocation on keystroke. Public Pages remains static/literal with no local runner. No vector/embedding/service dependency is added; measured recall or population gaps may justify revisiting this choice.

Private manual saving accepts every returned candidate regardless of assessment; malformed metadata remains a lead. Optional automatic personal saving is off by default and requires completed v7 or v8 assessment, supported resolved identity, relevance at least 75 and a configurable Signal threshold (initially 75). Private admission/exclusion decisions remain inspectable. Public inclusion keeps its separate owner/review boundary; no new exception or publication authority is introduced.

The existing React workbench owns Home, Library/Online/Combined scopes, candidates-first results, evidence beside results, selected comparison and frozen discussion. Typed view components stay internal. Following, capture, projects, refresh, jobs, exchange and public browsing remain supported. All-project scheduling expansion, public semantic search, specialized maps, new adapters and outcome learning remain future work.

Question saving uses the shared loopback Host/Origin/session-token API in development and built serving. The duplicate Vite mutation is retired. Context's verified owning rebind repairs only local installation identity after preservation; the current checkout supports a read-only plan handoff with no equipment application.

Mechanical tests and interactive fixture screenshots establish behavior under their conditions. Live research, fresh independent review and human usefulness remain separate evidence classes. Remote delivery, recurrence, new public records and stable release require separate authority.
