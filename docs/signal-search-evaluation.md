# Signal-search evidence and limits

The initial live study exposed weak acquisition depth, unsupported feature judgments, inaccessible sources and expensive timeouts. These are product findings, not successful admission evidence. The subsequent corrections preserve every retained attempt and use frozen evidence to avoid paying for the same discovery again.

The authorized initial study used fourteen discovery invocations, including two schema rejections, a tool-budget failure and a rejected overlapping-coverage count. Its substantive cases covered context efficiency, local knowledge, agent skills, controlled delegation, web design, small-business process, birds and museum preservation. The small-business and final museum searches exhausted their time budget during extraction; web design also cancelled. Frozen recovery can assess acquired evidence, but does not turn those original attempts into successful complete searches.

Two direct AI baselines were also observed. The direct context baseline produced a practical layered answer in 96 seconds with eight web calls. The direct local-knowledge baseline produced a more focused five-tool answer in about 135 seconds with nine web calls. The initial Signals local-knowledge search spent about 503 seconds on twelve web calls, collected 58 leads and 54 distinct entities, fetched 32 documents and assessed 19 entities; none met threshold 75. More catalog entries did not establish better research. Neither comparison proves universal superiority or measured human benefit.

The first controlled standard comparison used the same actual ISO catalogue evidence: the original ordinary-entity profile scored 38 and the fixed standard profile scored 75. The catalogue confirmed a current edition; full paid normative text and conformance outcomes were not inspected. This justified separating normative authority from social adoption, rather than renormalizing missing features. Popularity remains bounded attention, with independent applied evidence required for stronger adoption credit.

Corrections prompted by actual evidence and review include bounded discovery depth, feature-specific extraction schemas, exact source indexes, larger excerpts with complete short documents, ranked direct GitHub/Hacker News retrieval, own-origin exclusion that admits independent original research, literal JSON preservation, immutable excerpt projections, retired-judgment replay protection, actual status-check receipts and assessment cutoffs after acquisition. Each has a discriminating check; ordinary CI uses isolated fixtures without inference.

The built local workbench has been exercised with actual search, comparison, two manual saves, dismiss/reset, filters, private history and a no-web grounded follow-up. Manual saves below threshold are deliberate user choices. A target-only scheduled refresh and its repeat were observed with no alternate-entity admission or repeated completed job. Static Pages remains read-only; source access and model availability can still fail.

The larger Context concept gate is separate from the fourteen-invocation study. Its snapshot contains 140 concept names, definitions and source provenance. Early attempts are retained as a diagnostic baseline. The complete review/enhancement cycle remains a completion requirement; this initial source milestone does not claim that gate has passed. Scheduled inference and unattended publication are disabled by default and were left disabled during explicit one-shot evaluations.
