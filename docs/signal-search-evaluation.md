# Signal-search evidence and limits

The initial live study exposed weak acquisition depth, unsupported feature judgments, inaccessible sources and expensive timeouts. These are product findings, not successful admission evidence. The subsequent corrections preserve every retained attempt and use frozen evidence to avoid paying for the same discovery again.

The authorized initial study used fourteen research invocations in total: twelve pipeline/native attempts and two direct matched baselines. These included two schema rejections, a tool-budget failure and a rejected overlapping-coverage count. Its substantive cases covered context efficiency, local knowledge, agent skills, controlled delegation, web design, small-business process, birds and museum preservation. The small-business and final museum searches exhausted their time budget during extraction; web design also cancelled. Frozen recovery can assess acquired evidence, but does not turn those original attempts into successful complete searches.

The two direct AI baselines are included in that total. The direct context baseline produced a practical layered answer in 96 seconds with eight web calls. The direct local-knowledge baseline produced a more focused five-tool answer in about 135 seconds with nine web calls. The initial Signals local-knowledge search spent about 503 seconds on twelve web calls, collected 58 leads and 54 distinct entities, fetched 32 documents and assessed 19 entities; none met threshold 75. More catalog entries did not establish better research. Neither comparison proves universal superiority or measured human benefit.

The first controlled standard comparison used the same actual ISO catalogue evidence: the original ordinary-entity profile scored 38 and the fixed standard profile scored 75. The catalogue confirmed a current edition; full paid normative text and conformance outcomes were not inspected. This justified separating normative authority from social adoption, rather than renormalizing missing features. Popularity remains bounded attention, with independent applied evidence required for stronger adoption credit.

Corrections prompted by actual evidence and review include bounded discovery depth, feature-specific extraction schemas, exact source indexes, larger excerpts with complete short documents, ranked direct GitHub/Hacker News retrieval, own-origin exclusion that admits independent original research, literal JSON preservation, immutable excerpt projections, retired-judgment replay protection, actual status-check receipts and assessment cutoffs after acquisition. Each has a discriminating check; ordinary CI uses isolated fixtures without inference.

The built local workbench has been exercised with actual search, comparison, two manual saves, dismiss/reset, filters, private history and a no-web grounded follow-up. Manual saves below threshold are deliberate user choices. A target-only scheduled refresh and its repeat were observed with no alternate-entity admission or repeated completed job. Static Pages remains read-only; source access and model availability can still fail.

The larger Context concept gate is separate from the fourteen-invocation study. All 140 names in the current Context catalog were queried with their definitions and source provenance, and every query received a parent judgment. The main run retained 712 candidates: 621 scored and 91 unassessed. Its original outcomes remain 129 partial results, eight cancellations and three failures. It made 976 search calls, fetched 1,041 documents and recorded 278 model invocations with about 6.1 hours of summed run time. Fourteen eligible writes include successors to existing records rather than fourteen distinct new entities.

The gate exposed defects beyond acquisition quality: admission inspected unselected unsafe examples, private history reused public privacy validation, the discovery wire allowed mismatched feature indicators, and ambiguous candidate identities blocked unrelated reviews. Each defect received a discriminating regression and a correction. A subsequent real determinism query passed the revised discovery wire and assessed six candidates. Whole-proposal property-testing recovery assessed four unique identities while preserving the PBT/Hypothesis collision as ambiguous and unassessed.

Bounded recovery and refinement created separate receipts. Modeling recovery assessed four of five candidates; UML remained unassessed after its limit. Monitoring assessed all six; static hosting assessed four of five, preserving an inaccessible service as unassessed. Focused SLSA and SemVer reviews stayed below admission. The SPEC licensing review corrected conditional eligibility and was applied as an explicit manual successor to an existing record; its focused score differs from the merged score. No recovery changes an original failed or cancelled status, and refreshed source documents are distinguished from identical frozen evidence.

Captured main-run receipts report 24,833,107 input tokens, including 16,116,864 cached input tokens, and 769,468 output tokens. These cover 262 usage receipts, not all 278 attempted invocations, and exclude separate recovery and refinement. All captured model references are `gpt-6.1-sol`; dollar cost remains unknown. Token totals and cached totals must not be added together. The breadth of this evaluation is expensive and does not establish that every ordinary query needs this volume.

The local workbench's **Find sources without AI** action returned fifteen ranked GitHub, Hacker News and Wikipedia links through three public API calls, with zero model calls and no Corpus changes. The links are explicitly unassessed. Its actual browser checks passed accessibility and overflow checks at desktop, tablet and phone widths. Full verification also passed in a disposable clone without private state or model access.

The final independent review examined all thirteen native records and their active merged evidence, together with the changed source paths. It found unsupported formal-authority credit in the SPEC record. A review-metadata successor withdrew that judgment without changing its original observation or evidence, and the merged score replayed from 79 to 59. The reviewer confirmed closure with no remaining blocking finding. SPEC remains a retained, explicitly corrected record below automatic admission; it is not counted as a current high signal.

The Corpus contains thirteen native records, ten currently at or above 75, alongside nineteen retained legacy bundles containing twenty options. Nine of those high native records came from the larger concept gate; the ISO record came from the initial study. Exact older full-text context was unavailable for ISO, Vercel Agent Skills and AGENTS.md during the final independent review; their stored excerpts and structural replay remain intact. Current merged scores can combine compatible observations from multiple reviewed runs and must not be presented as one fresh judgment.

Ordinal scores are not calibrated probability, demonstrated user benefit or proof of deployment. The gate is complete as a discovery, review and enhancement exercise with its failures and unknowns preserved; it does not establish that every query succeeds or produces a high signal. Scheduled inference and unattended publication remained disabled during the one-shot evaluation.
