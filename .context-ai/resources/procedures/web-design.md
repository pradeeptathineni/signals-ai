# Impeccable instruction-only adapter

Selected primary procedure: Impeccable 4.5.0 at the revision in [sources.lock.json](../sources.lock.json). This adapter selects documentation, with upstream text and notices preserved. The optional launcher, downloads, hooks, native edits, pin commands and extensions are unavailable here and require separate decisions/authority. Skip their setup and read existing project context directly. This adaptation is Context policy; it does not claim native Impeccable activation.

At a new design stage read [new work](../sourced/impeccable/design/reference/new-work.md), [shape](../sourced/impeccable/design/reference/shape.md) and [craft floor](../sourced/impeccable/design/reference/craft-floor.md); load only applicable web instructions. At review read [critique](../sourced/impeccable/design/reference/critique.md) and [audit](../sourced/impeccable/design/reference/audit.md); use actual browser evidence. For final refinements read [polish](../sourced/impeccable/design/reference/polish.md). The full [archived entrypoint](../sourced/impeccable/design/instruction.md) supplies routing context, not authority to execute an excluded binary.

Explicit product truth, user brand, repository authority and this adapter win over advisory preferences, prompts for redundant confirmation, and upstream delegation. Use a bounded self-critique in the same agent unless separately authorized. Do not create competing PRODUCT/DESIGN records when the project has equivalents. Scores are heuristic labels, not calibrated beauty measurements. A command's absent binary does not block direct guidance.

[Anthropic frontend-design](../sourced/anthropic/design/instruction.md) is a reference/lightweight fallback used only when primary guidance is unavailable or excessive for the task. Do not load both manifestos at once. [Vercel web-design-guidelines](../sourced/vercel/web/instruction.md) is a targeted audit: fetching latest upstream rules is an explicit proposed evidence refresh, never a silent active-pin change. WCAG remains the normative accessibility source.
