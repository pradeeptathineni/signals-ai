# Web design judgment

Policy, informed by the pinned Impeccable workflow: understand audience/job, inspect the existing product, compare a few appropriate directions, select one, define tokens, build, use in a browser, critique, revise and prepare delivery. Read [the selected procedure](../../procedures/web-design.md) at design/review stages. Use one primary style procedure per stage. Anthropic frontend-design is a fallback/reference; Vercel guidelines are an audit.

Record brief reasons for hierarchy, typography, palette, spacing, motion and responsive choices. A quiet/expressive option bounds a project decision; neither implies a second design library. Preserve explicit brand direction, including intentional Matrix rain/neon. Upstream anti-pattern preferences are advisory taste, not WCAG. Deterministic checks cannot judge aesthetic quality. A new screenshot baseline is evidence of appearance, not approval.

Use project-owned/licensed assets and truthful content. Review the whole page and meaningful states, not only the hero. Spend expressive detail where it helps the primary job; avoid automatic identical-card layouts. Respect reduced motion and provide a static fallback for signature effects.
