# Architecture

[ADR-017](docs/architecture/ADR-017-query-assessment-and-library.md) owns active native v5, type-rubric v8 and numeric query relevance; v4/v7 remain historical readers. `packages/domain/src/search-assessment.ts` validates rubric sufficiency and arithmetic; `query-exchange.ts` binds exported query judgments by source ID. Historical policy readers remain. Home/Search/Projects/Library/Following share typed candidate/evidence/comparison/discussion views. Library meaning matching is one submitted, permission-scoped no-web operation with literal fallback. The shared local API owns question saving in development and built serving.

[ADR-016](docs/architecture/ADR-016-corpus-first-project-experience.md) gives Signals one corpus-first Search / Projects / Library / Following workspace and ownership of general project opportunities. A MiniSearch projection unifies eligible native and legacy records; private annotations and permission-scoped project snapshots remain local. Context owns AI equipment selection and delivery. The shared handoff is advisory, with no browser command executor or duplicate installer.

[ADR-015](docs/architecture/ADR-015-native-research-replacement.md) makes one native research task the shared engine. Native brief v3 retains the readable answer before per-item source/record validation. Legacy brief/proposal formats are historical ingestion decoders. Explicit frozen reassessment is a specialist; ordinary research has no second interpretation stage. Native-authored query groups share compatible unassessed acquisition while keeping separate per-interest reasoning. Due maintenance checks unchanged/denied primary material before inference.

[ADR-013](docs/architecture/ADR-013-grounded-priority-and-discovery-provenance.md) corrects recommendation grounding and qualifies discovery labels. Contextual priority v2 holds ungrounded use/wrap/adapt proposals at study without hiding the lead or changing intrinsic admission. Source transport happens outside the writer lock; optional state failures remain gaps. Private source feedback binds explicit entity votes to verified configured introducing parents.

[ADR-012](docs/architecture/ADR-012-refreshed-acquisition-and-priority.md) adds reviewed optional acquisition and extraction behind one live kernel. The document parser preserves original outlinks and heading/table addresses behind pinned safe HTTPS transport. Private source-health, annotations and inbox use the existing writer; query-only priority/delta/relations never become canonical evidence. A repeated source scan is not a new discovery, and a changed source page is not automatically a meaningful claim change.

Signals has one bounded live discovery kernel and two host integrations: an invoking Agent Skill and an explicitly configured headless Codex CLI. Local UI, query discovery and Corpus refresh call that kernel. Literal/ranked Corpus retrieval remains a separate offline operation.

The model interprets questions, plans domain-appropriate acquisition, resolves conservative identities and supplies source-bound semantic observations. Code owns the fixed score formula. Discovery supplies source-bound observations which are checked against safely fetched text. Optional extra grounded review (`--review` or Settings) revises them over frozen excerpts without web access; ordinary product routes do not require a second model pass. Native hosts perform source grounding in their invoking agent. Quote checks establish text occurrence only; model judgments remain fallible.

Historical six-feature policies retain fixed normalizers and type-specific currentness windows. The v7/v8 successors use four type-rubric dimensions with explicit unknown/provisional/null states and source-bound evidence ceilings. v8 permits explicitly bound inspected applicability at limited level 1 for ordinary resources; v7 replay retains its original mapping. Repeated origins cannot manufacture independent support. Relevance belongs to the query. Personal manual saving accepts unassessed leads; optional automatic private saving additionally requires completed assessment and relevance at least 75. Public inclusion keeps its separate existing boundary. Legacy minimum-review meaning applies only to historical records.

Entity evidence is immutable. An observation's stable basis binds entity, source bytes, feature and quote; changed indicator/status/independence creates a successor judgment. Scoring excludes superseded judgments; replay of an old observation cannot restore credit. Types retain URI identities. Monorepo subresources remain distinct; conflicting URI aliases fail closed. Per-entity atomic rename and a cooperating writer lock permit safe retries without claiming batch transactionality.

The CLI owns authentication. A disposable read-only runner disables shell, hooks, plugins, apps, memories, MCP execution and delegation. Process-group cancellation and output/time/tool limits bound it. Retrieved instructions cannot change permissions. Evidence fetching validates DNS, pins the connected address, checks redirects and limits bytes/time. Failed sources remain inspectable.

Local endpoints accept loopback Host and same-origin requests. Mutations require a random session token; schemas reject arbitrary commands/paths. UI saves select server-owned results. Asset serving denies private files and symlink escapes. Pages contains public records only and has no live runner.

Scheduled discovery uses durable slots and one lease. Completion follows retained results and canonical saves; interrupted inference becomes uncertain rather than silently repeated. Publication defaults to local-only. Existing build/Pages CI remains the hosting path.

[ADR-017](docs/architecture/ADR-017-query-assessment-and-library.md) governs new scoring/retrieval; [ADR-011](docs/architecture/ADR-011-live-signal-search.md) retains historical discovery/scoring meanings. [ADR-009](docs/architecture/ADR-009-database-retirement-and-signal-admission.md) governs database retirement and retained legacy admission; [ADR-010](docs/architecture/ADR-010-ranked-word-retrieval.md) preserves historical ranked retrieval. Frozen schema-v1 exchange and private snapshots retain original identities, dates and policy meanings.
